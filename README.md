# محلل السعرات الحرارية الذكي (Food Calorie Analyzer)

تطبيق ويب متكامل لتحليل صور الطعام، وتقدير السعرات الحرارية، واستخراج القيم الغذائية باستخدام **Groq Vision API**.
التطبيق مبني بالكامل باستخدام تقنيات خفيفة ومباشرة: Node.js و Express و Vanilla JavaScript (بدون React).

## المتطلبات الأساسية

- Node.js (الإصدار 18 أو أحدث)

## طريقة التثبيت والتشغيل

1- تثبيت الحزم المطلوبة:
```bash
npm install
```

2- إضافة مفتاح GROQ_API_KEY:
- في بيئة التطوير المحلية، قم بنسخ ملف `.env.example` إلى `.env` وأضف مفتاح API الخاص بك هناك.
- في بيئة الإنتاج (مثل Render)، ستقوم بإضافة المتغير في لوحة التحكم (انظر قسم النشر).

3- تشغيل الخادم:
```bash
npm start
```

## النشر على منصة Render

التطبيق مهيأ تمامًا للعمل على منصة Render بدون أي تعديلات برمجية. اتبع الخطوات التالية:

1. قم بربط مستودع GitHub الخاص بك في منصة Render واختر إنشاء خدمة ويب جديدة (**Web Service**).
2. في إعدادات النشر، تأكد من مطابقة الأوامر التالية:
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
3. انتقل إلى قسم **Environment Variables** وأضف المتغير التالي:
   - **Key**: `GROQ_API_KEY`
   - **Value**: `(ضع مفتاح Groq API الخاص بك هنا)`

بمجرد الانتهاء من النشر واكتمال البناء، سيعمل التطبيق مباشرة وبكفاءة.

## طريقة الاستخدام

1. افتح الموقع من المتصفح (يدعم الهواتف وأجهزة سطح المكتب).
2. انقر على **التقاط صورة** لفتح كاميرا الهاتف والتقاط صورة لطعامك، أو انقر على **رفع صورة** لاختيار صورة من جهازك.
3. راجع الصورة التي تظهر في شاشة المعاينة.
4. انقر على **تحليل الصورة**.
5. انتظر بضع ثوانٍ حتى يقوم الذكاء الاصطناعي (نموذج الرؤية من Groq) بتحليل الصورة.
6. ستظهر لك القيم الغذائية الكاملة: السعرات، البروتين، الكربوهيدرات، الدهون، واسم الطعام، مع نصائح صحية!
